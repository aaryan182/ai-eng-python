2) LLM as a Router (Key Idea)

We ask the LLM:

“Given the current state, what should we do next?”

It returns a route name not text.

Example output:

{
  "next": "research"
}


This is how LangGraph enables dynamic branching.

6) Conditional Branching (LangGraph Magic)

LangGraph lets you route dynamically

def route_selector(state: PlanState):
    return state["route"]


Then register branches:

graph.add_conditional_edges(
    "router",
    route_selector,
    {
        "research": "research",
        "rag": "rag",
        "simple_answer": "final",
        "fail": "failover"
    }
)


This is EXACTLY how LLM-driven routing works.

10) Failover Node (Critical for Production)

When something goes wrong -> fallback.

def failover_node(state: PlanState):
    if state["retries"] >= 2:
        state["final_output"] = "Unable to complete task reliably."
        return state

    state["retries"] += 1
    state["route"] = "simple_answer"
    return state


11) Final Node
def final_node(state: PlanState):
    prompt = f"""
Provide a clean final answer for:

Task: {state['task']}

Context:
{state.get('summary') or state.get('research_notes')}
"""
    state["final_output"] = call_llm(prompt)
    return state
